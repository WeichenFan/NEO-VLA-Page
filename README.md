# NEO-VLA project page

Static project page for *From Pixels to Actions – Towards Native Vision-Language-Action Policies* (NEO-VLA).

- `index.html` – the page (no build step)
- `static/figures/` – figures exported from the paper PDFs
- `static/videos/` – real-robot rollouts, H.264 960x540, no audio
- `static/posters/` – first-frame posters for the videos

Preview locally with `python3 -m http.server` and open http://localhost:8000.
Serve with GitHub Pages from the repository root.
